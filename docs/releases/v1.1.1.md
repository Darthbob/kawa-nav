The ride's chart and its map, made to be read closely: the chart zooms, and the track takes the colours of the value the chart shows. How KawaNav talks to the bike is unchanged from 1.1.

### New

- **The chart zooms.** Pinch it to look at a stretch of the ride closely, move along it with two fingers, or double-tap to zoom in; the button at the corner of the card shows the whole ride again. One finger still marks the second under it, now the one closest in time to the finger. Zoomed in, the value scale follows what is shown, so a small change fills the chart, and the time axis reads minutes and seconds. Picking another value keeps the stretch, so two values can be compared over the same seconds. The chart is a little taller than before.
- **The track takes the chart's colours.** It was always coloured by speed; it now follows the value picked for the chart — blue where it was lowest, then green, orange, red where it was highest (for the torque, what the engine gives). The scale runs between the 2nd and the 98th percentile, so one odd second does not turn the rest of the ride one colour, and a second without the value is grey. The note under the map says which values the colours stand for.
- **The map shows where the chart is zoomed.** While the chart shows a stretch of the ride, the rest of the track is faded, so the stretch is easy to find on the map.

### Not yet tried on a bike

Everything above is covered by unit tests (259 in the app; `TrackViewTest` is new, `ChartViewTest` gained the zoom's stretch, the second a touch finds and the axis labels), but this version has not been on a phone yet. Worth checking when you can: on a recorded ride, pinch the chart and move along it with two fingers — the page should not scroll while you do — then pick another value and see the stretch and the map's colours follow; the note under the map should name the values. A report should include Settings → "Export the log and the capture" and a screenshot of the ride. Unchanged from 1.1: the values and warnings, what the two traction-control pairs report, which rotation rate is which axis ([docs/PROTOCOL.md](https://github.com/Darthbob/kawa-nav/blob/v1.1.1/docs/PROTOCOL.md)), the dashboard's capability answer, writing riding modes 5-7 in the debug build and the byte 88 wheel-speed setting.
