# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue or pull request:
use **[Report a vulnerability](https://github.com/jackyes/kawa-nav/security/advisories/new)**
(GitHub private vulnerability reporting, under the repository's **Security** tab).

Useful to include: what is affected (app version or commit), how to reproduce it, and what an
attacker could do with it. You will get an answer as soon as possible; please give time for a fix
before making the problem public.

## Scope

- The KawaNav Android app in this repository: its Bluetooth link to the bike, the data it stores
  on the phone (ride logs, bike values, offline maps) and what it reads from notifications.
- Problems in the code KawaNav is forked from can also be reported upstream at
  [Darthbob/kawa-nav](https://github.com/Darthbob/kawa-nav).

Not in scope: the bike's own firmware and Kawasaki's Rideology app.

## Supported versions

Only the latest version on the `main` branch gets security fixes.
